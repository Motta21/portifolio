Sobre Mim

Olá! Sou graduando em Análise e Desenvolvimento de Sistemas com uma foco profundo por hardware, software e como eles se conectam para resolver problemas reais.

Atualmente, atuo como Pesquisador no INPE (Instituto Nacional de Pesquisas Espaciais) através do Programa Educação. Minha pesquisa envolve o desenvolvimento de soluções de baixo custo para monitoramento ambiental, combinando microcontroladores, manufatura aditiva (impressão 3D) e aprendizado de máquina.

Tenho experiência em projetos de iniciação científica (PIBIC/PIBITI). Meu objetivo é criar sistemas inteligentes e resilientes que democratizem o acesso aos dados ambientais e promovam inovação científica.

Monitoramento Ambiental IoT

Infraestrutura completa de telemetria. Transmissão de dados via protocolo MQTT (HiveMQ Cloud) para um servidor Ubuntu usando Cloudflare Tunnels. Visualização através de Dashboards web em PHP.
